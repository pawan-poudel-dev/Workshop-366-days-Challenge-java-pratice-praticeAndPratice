- **Topics:** If/else, switches, loops

## 📋 Java Naming Conventions

✅ **Classes:**
- `AIModel.java`
- `PersonalPlan.java`
- `SubscriptionGUI.java`

✅ **Variables:**
- `int maxAttempts;`
- `String userName;`
- `boolean isActive;`

✅ **Methods:**
- `calculatePrice()`
- `getUserInput()`
- `displayMenu()`

❌ **Avoid:**
- `test.java`
- `file1.java`
- `code.java`
